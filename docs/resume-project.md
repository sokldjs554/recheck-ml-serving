# 이력서용 RECHECK 소개

아래는 확인된 프로젝트 사실에 근거한 초안입니다. 이름·학력·다른 경력은 제공받지 않아 포함하지 않았습니다.
실제 지원서의 기여 설명은 본인이 수행·검토한 범위와 일치하도록 작성합니다.

## 프로젝트 항목에 넣을 짧은 소개

**RECHECK | AI 결과의 최신성을 실행 시점까지 검증하는 Python 백엔드**  
AI 협업 프로젝트 · Python / FastAPI / PostgreSQL / scikit-learn

- 근거가 변경된 뒤 이전 AI 결과를 사용하는 문제를 재현하고, 검증과 내부 작업 기록을 같은 SQL 트랜잭션으로 처리하는 백엔드와 실제 API 데모를 제작했습니다.
- SQLite·PostgreSQL에서 동일한 9개 고정 사건 순서로 세 방식을 비교했습니다. 오래된 결과 6건 중 별도 확인 방식은 5건을 허용했고 원자적 기록 방식은 0건을 허용했습니다. 정상 작업 거절과 중복 기록도 함께 확인했습니다.
- CPU 추론의 프로세스 격리·수용 제한을 비교하고, 지연뿐 아니라 시간 내 성공·거절·메모리 비용을 기록했습니다. 동시성 테스트, 분산 추적, 배포·복구 실험과 재현 명령을 공개했습니다.

## 지원 동기 문항에 연결할 초안

Python과 LLM·AI/ML을 경험하면서, 모델의 응답을 실제 기능으로 연결할 때 생기는 서버 문제에 관심을 갖게 되었습니다.
RECHECK에서는 추론이 성공했더라도 근거가 바뀌면 결과를 그대로 사용할 수 없다는 문제를 다뤘습니다.
토스뱅크에서는 여러 AI 제품이 공통으로 필요로 하는 최신성 검증, 시간 예산, 장애 관측을
재사용 가능한 서버 기능으로 만드는 데 기여하고 싶습니다.

## 서류에 실을 사실과 본인 수행 기록의 구분

- 위 프로젝트 기능과 수치는 저장소의 실행 근거로 확인할 수 있습니다. 이를 혼자 구현한 경력이나 실사용 사업 성과로 바꾸지 않습니다.
- 사용자가 현재 제공한 개인 경험은 Python·LLM·AI/ML 경험, AI와 반복 오류의 해결 방법을 비교·통합한 경험입니다.
- 이번 작업에서 사용자는 조사 범위·지원 목적·자료와 데모 개선 요구를 제시했고 AI가 구현·검증을 지원했습니다. 별도의 직접 수정 경험은 실제 수행한 뒤 추가합니다.
- 프로젝트 소개는 서류의 한 요소입니다. 공고의 자격 요건, 전체 이력서와 다른 경험까지 포함한 합격 가능성을 이 자료만으로 판단할 수는 없습니다.
