# 데모 제목과 결과 안내 개편

2026-10-16 · 기존 실행 흐름을 유지한 화면·문구 개편

## 제목과 첫 화면

대표 제목은 **AI 응답 검증과 서버 부하 실험**입니다. 질문형·작업 보고형 제목을 내용이 드러나는 명사형으로 정리했습니다.

| 경로 | 제목 | 확인 범위 |
|---|---|---|
| 첫 화면·실행 재현 | 정보 변경과 답변 기록 | 실제 API의 이전 답변 차단·새 기록·동일 키 재시도 |
| 모델 부하 | 요청 증가와 서버 응답 | 저장된 로컬 측정의 투입량·유효 응답·거절·회복 |
| 장애 복구 | 장애 원인과 복구 결과 | 저장된 모델 오류·SQL 대조와 별도 Kubernetes 복구 |

첫 화면의 과부하 요약은 부하 화면과 같은 `serving-evidence.json`에서 계산합니다. 초당 120건은 목표 요청률, 약 67.6건/초는 두 과부하 구간의 300ms 이내 유효 응답률 평균입니다. 180초 로컬 실험 중 해당 구간의 관측이며 공개 서버나 상담 체험의 처리량이 아닙니다.

기존 CaseFlow와 공유 실행 버튼을 유지했습니다. 결과 옆에는 차단 이유, 새 답변의 기록 조건, 재시도의 작업 ID 확인 위치를 추가했습니다. 상세 문서·시뮬레이션 화면의 문장형 제목도 정리했습니다.

## 시연과 글꼴

새 화면에서 로컬 Python API·SQLite로 6단계 실행과 비교 화면 왕복을 다시 촬영했습니다. 실제 요청과 응답을 사용하며 응답 가로채기·합성 프레임·재생 속도 변경은 없습니다. MP4·WebM과 포스터를 갱신했습니다. 브라우저가 확인한 WebM 길이는 35.44초입니다.

새 문구에 필요한 한글을 포함하도록 기존과 같은 Noto Sans KR 가변 글꼴의 서브셋을 재생성했습니다. 라이선스 파일은 유지했습니다.

## 검증

- 프런트 단위 검사 44개 통과, TypeScript·Vite 빌드 통과.
- 로컬 브라우저 검사 57개 통과: 대표 체험 10, 기본 흐름 18, 근거 변경 12, 비교 7, 서빙 6, 영상·반응형 4.
- 1440·768·390·320px에서 대표 제목, 단일 h1, 문서 넘침과 글꼴 로딩 후 화면 확인.
- 실제 API 실행의 화면 이동 후 세션·작업 ID·로그 유지와 추가 요청 방지 확인.
- 로컬 SQLite 백엔드 검사 140개 통과. `RECHECK_NETWORK_TESTS=1`, `OTEL_TRACES_SAMPLER=always_on` 조건.
- 측정 요약 세 종류의 원본 대조 통과. 측정 원본은 변경하지 않았습니다.

최초 백엔드 실행은 작업 환경에 상속된 1% 추적 샘플링 때문에 trace 확인 4개가 실패했습니다. 서버 코드를 바꾸지 않고 전체 샘플링 조건으로 실행해 140개 통과를 확인했습니다. 공개 서버의 샘플링 설정은 이번 작업에서 변경하지 않았습니다.

## 해석 범위

공개 점검의 첫 지연을 서버 시작 지연으로 단정하던 화면 문구를 수정했습니다. 단계별 시간이 없어 원인은 미확정입니다. 점검 전체 과정의 시간이며 단일 모델 추론 지연이 아닙니다.

이번 로컬 검증은 공개 배포 확인과 별개입니다. 새 부하 실험·Kubernetes 실험·장기 SLA 검증·실기기 Safari 검사·사용자 이해도 조사는 수행하지 않았습니다. 기존 새로고침 이후 상태 복원 한계도 유지됩니다.
